# بيان — مصحف رقمي وقفي (Bayan Quran)

تطبيق قرآن كريم وقفي مجاني مبني بـ **React 19 + Vite 8 + Tailwind CSS v4** مع دعم كامل للعمل دون اتصال (PWA) ومصحف بالرسم العثماني، ألوان التجويد القياسية، التفسير الميسر، الحفظ، ومجالس الختمة الجماعية.

## التشغيل والتطوير

> ملاحظة: يُفضل تثبيت الحزم عبر `bun install` أو `npm install --legacy-peer-deps`.

```bash
# التشغيل في وضع التطوير (المنفذ 3000)
npm run dev

# فحص الأنواع والاختبارات
npm run lint
npm test

# البناء الثابت للواجهة (مجلد dist/)
npm run build

# تشغيل الإنتاج الكامل (مع خادم الختمة الجماعية الآمن)
npm start
```

## النشر الساكن (Static Hosting) vs الخادم الكامل

- **للقراءة، الصوت، التجويد، الحفظ، المفكرة، ومصمم البطاقات:** يكفي نشر محتويات مجلد `dist/` بعد تنفيذ `npm run build` على أي استضافة ثابتة.
- **لغرف الختمة الجماعية المزامنة حياً:** استخدم `npm start` (`NODE_ENV=production`) مع تخصيص المتغير البيئي `KHATMA_ADMIN_SECRET` في الإنتاج، وتخزين مجلد `data/` على قرص دائم (Persistent Volume) أو قاعدة بيانات دائمة.

## المصادر والحقوق (Attribution)

- **النص القرآني بالرسم العثماني والتفسير الميسر:** واجهة [AlQuran Cloud API](https://alquran.cloud/api).
- **توقيت الكلمات والتلاوات:** [Quran.com API](https://quran.com) وملفات التلاوات الصوتية من [EveryAyah](https://everyayah.com).
- **الخطوط العربية:** `Amiri Quran` و`Amiri` و`Cairo` و`Noto Naskh Arabic` و`Reem Kufi` عبر Google Fonts.
- **الخصوصية:** تُحفظ خواطر التدبر وإشاراتك المرجعية وسجل الورد محلياً على جهازك فقط. عند استخدام البحث الشامل تُرسل عبارة البحث إلى `api.alquran.cloud`.
